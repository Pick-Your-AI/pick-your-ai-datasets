# Source rights

## Principles

- **Metadata only.** This repository records facts about datasets with citations. It never copies dataset contents, and never copies substantial text, figures or tables from dataset cards or papers. Write original summaries.
- **Rights are per version and per use.** Training, evaluation, commercial use, redistribution, derivative works and metadata display are separate permissions. Each cites the clause or statement it comes from.
- **Public is not permitted.** A downloadable file, an open repository or a public paper grants no permission by itself.
- **Custom licenses stay custom.** Map to an SPDX identifier only when the license is exactly that license. Otherwise record the license name and the source of its text.
- **No legal advice.** Rights assessments record what sources state and what a rights reviewer accepted. They do not certify anyone's compliance.

## Discovery sources

| Source class | Owning package | Recordable without further review |
| --- | --- | --- |
| Academic and preprint | DATA-02.02 | Identity fields and the paper-revision link |
| Official and government | DATA-02.03 | Identity fields, landing page, stated license family |
| Commercial and vendor | DATA-02.04 | Publicly visible product metadata only; no paid or account-gated material |
| Community hubs | DATA-02.05 | Host identifier and revision as published |
| Specialized domains | DATA-02.06 | Public metadata and public access-gate descriptions only |

Discovery is manual or uses documented, permitted APIs within their published limits. Crawling, scraping without permission, bulk downloading and circumventing access gates are prohibited. Work package DATA-02.01 approves the detailed protocol.

## Consent and personal data

Record what the dataset's own documentation says about consent, de-identification and opt-out. If it says nothing, record unknown. Never handle personal data to verify a claim. Records with personal or sensitive data carry a sensitivity flag (DATA-05.03).

## Withdrawals and disputes

A takedown, withdrawal or deprecation is a sourced, dated event that changes publication state (DATA-05.05). Disputes are recorded without repeating unverified allegations.

## Removal requests

If committed material should not be public, report it privately through `SECURITY.md`. A maintainer removes it through the reviewed process and records the action.
