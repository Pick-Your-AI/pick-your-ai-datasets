# Source-use review (unaccepted template)

Copy this template into a Markdown research note. Replace placeholders only with
observed public metadata; never include credentials, signed URLs, private contacts
or dataset contents. A blank or unknown field does not grant permission. This
template does not appoint an owner or request a source-site account.

Acceptance of this note does not accept a dataset record, permit publication,
waive per-version/per-use rights, authorize spending, or override the campaign's
