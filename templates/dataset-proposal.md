# Dataset or benchmark proposal

Copy this into an issue, or use it to prepare `catalog/proposals/<record_id>.json`.

- **Record ID:** `dataset.<slug>` or `benchmark.<slug>`
- **Title, as published:**
- **Publisher and primary source:** URL, publisher, access date
- **Versions:** the label as published, or "unversioned"; release date if stated; splits and sizes with units, or unknown
- **License, per version:** the license name as stated; SPDX only if exact; source URL
- **Access classification:** Open / Registration Required / Gated/Approval / Restricted/Sensitive / Commercial/Paid / Mixed
- **Permissions:** training / evaluation / commercial / redistribution / derivatives / metadata display. Give each as allowed, conditional (with conditions), prohibited or unknown, with its source.
- **Consent and personal data:** what the documentation states, or unknown
- **Relationships:** derived from, subset of, superseded by, translated from or mirrors, each with a source
